SecChain

Secrets that stay in your Keychain, not your files

SecChain is a per-repository secret manager for macOS. API keys, access tokens, and other development secrets live only in the macOS Keychain — never in a .env file that a commit, a backup, or an AI coding agent could read. Secrets sync across your Macs through iCloud Keychain and reach the command that needs them without ever being printed.

Command line

One command to run, one to check

Store a secret once, then hand it to any command through secchain run. The value is read from a hidden prompt or from standard input — it is never accepted as a command-line argument, so it cannot end up in shell history. 

# read from a hidden prompt
secchain set OPENAI_API_KEY

# names only, never values
secchain list

# secrets become env vars
secchain run -- npm run dev
How it works

One store, every front end

Per-repository

Secrets are scoped to the repository they belong to, identified from the Git remote — the same secret name in two repositories is two separate items.

Synced through iCloud Keychain

A secret added on one Mac is available on your others once iCloud Keychain is on. SecChain stays fully usable locally when it is off.

Never printed

There is no command that prints a secret value to standard output. secchain run hands values to the process that needs them and nothing else.

One store for macOS, iOS, and the CLI

A secret registered in the macOS app is usable from the command line in that repository, the iOS app manages the same synced items, and the other way around.

Protection levels

Authentication is opt-in per secret

The default keeps everyday use free of prompts; raise the level for a secret that deserves more friction.

LevelSyncsAuthentication
Standard (default) Yes Only when a value is revealed in an app
Confirm Yes Every secchain run, and before update or delete — on the Mac or on your paired iPhone
Device-bound Never Every read, enforced by the Keychain itself
Remote approval

Approve a run from your iPhone

A Confirm secret asks for authentication before secchain run reads it. Pair a Mac with your iPhone and that question can be answered there instead: the app shows which Mac is asking, for which repository, which secrets, and which command, and Face ID signs the approval. It covers Macs without Touch ID, SSH sessions where no prompt can be shown, and commands an AI coding agent starts while you are away from the Mac. 

# pair this Mac with the iPhone whose number you type
secchain pair

# ask the iPhone for this run
secchain run --approve-remotely -- npm run deploy

# or let the iPhone answer every confirm authentication
secchain pair confirm-on-iphone on

The request travels through the private database of your own iCloud account, which nobody else can read — the developer included — and it never contains a secret value. Only the key in your iPhone's Secure Enclave can approve, so nothing else that reaches your iCloud account can answer for you.
