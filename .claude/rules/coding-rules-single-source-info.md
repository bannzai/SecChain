# Single source of truth

Apply the single-source-of-truth idea to documentation, code comments, data structures, and state. The same information is written once, and the same thing or state exists once.

- Do not repeat in comments what the code already shows (lists, mappings, constant values).
- For logic, do not write comments that describe what the code does.
- For definitions, write what the definition represents.
- Do not create intermediate representations. Rule, reasons, and examples: `coding-rules-no-intermediate-representations.md`.
