SecChain は開発プロジェクトの Secret を .env ファイルではなく Keychain に置き、必要なコマンドへ値を表示せずに渡します。

Mac では secchain コマンドが API キーやトークンをリポジトリごとに保管し、環境変数としてコマンドへ渡します。このアプリでは同じ Secret を iPhone や iPad から扱えます。プロジェクトが必要とする Secret を確認し、Mac が手元になくても追加でき、Face ID や Touch ID の認証の後に値を表示できます。Mac の代わりに認証を返すこともできます。保護された Secret を使うコマンドが Mac で始まると、何が求められているかを表示し、Face ID の認証で承認します。

できること

- Secret はリポジトリに属します。同じ名前でもプロジェクトごとに別の値を持てます
- 値は端末の Keychain だけに保存されます。ファイル・ログ・サーバーには書き出しません
- iCloud Keychain を選んだ Secret は Apple のエンドツーエンド暗号化で端末間を移動します。端末に留める設定の Secret はそこから出ません
- 値は既定で隠れています。表示するには必ず認証が必要です
- 保護レベルを Secret ごとに選べます。通常のコマンドでは認証を求めない、読むたびに求める、Keychain 自身に強制させる、の 3 段階です
- ペアリングした Mac から、保護された Secret を読むコマンドの承認を求められます。どの Mac が求めているか・リポジトリ・Secret の名前・コマンドを確認して Face ID で承認します。Touch ID の無い Mac、SSH のセッション、離席中に AI コーディングエージェントが始めたコマンドで使えます

プライバシー

SecChain は何も収集しません。アカウント・分析・広告はありません。開発者は Secret の値も名前も、どのプロジェクトで作業しているかも見られません。承認の依頼はあなた自身の iCloud を通り、Secret の値を含まず、開発者からは読めません。

SecChain は MIT ライセンスのオープンソースです。macOS アプリとコマンドはプロジェクトのサイトから配布しています。
